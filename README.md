# SmartShop AI 👟

SmartShop AI is a React Native eCommerce application designed to provide
a smart, attractive, and user-friendly shoe shopping experience.

## Project Overview

SmartShop AI allows users to browse shoes, search for products using
natural-language queries, view detailed product information, select
sizes, add products to cart, and receive smart product recommendations.

## Features

- 🏠 Attractive SmartShop home page
- 👟 15+ sample shoe products
- 🔍 Smart product search
- 🤖 AI-style conversational search
- 💰 Price-based filtering
- 🏷️ Brand-based filtering
- ⭐ Product ratings
- ❤️ Favorite products
- 👞 Product details page
- 📏 Shoe size selection
- 🛒 Add to Cart
- ⚡ Buy Now interface
- 📱 Responsive React Native design

## Example Search

Users can enter natural-language queries such as:

"Running shoes under ₹5000"

The application analyzes the query and displays matching products
based on the requested category, brand, and price.

## Technologies Used

- React Native
- Expo
- TypeScript
- Expo Router
- React Native StyleSheet
